# wherdr 1.2.0

This release brings full omp support to the conversation view: transcript, reasoning, running
actions and results, model and thinking controls, `!` / `$` commands, restart, icon and themes.

- Make wherdr your own with Titanium, Graphite, Neon Purple and omp themes, a compact agent list,
  and a configurable focus effect for the message field.
- Reply to several quoted questions in one message, with optional quote tokens. Sent messages
  appear immediately, including clear queued and retry states.
- Run or copy commands suggested by an agent. Running always asks you to confirm the full
  command first.
- Set a maximum passkey unlock age and lock all devices at once.
- Read Codex update and weekly-limit notices, attach supported files, and zoom conversation
  images. Terminals gain clickable links and Nerd Font symbols.
- Fix message delivery around interactive menus and other writers, recover cancelled queued
  attachments, and improve mobile sheets and connection recovery.

See `CHANGELOG.md` in the v1.2.0 source tree for the full list of changes.

## Updating

For the published Docker image, run this in your wherdr directory:

```sh
docker compose pull && docker compose up -d
```

If you pin `WHERDR_IMAGE`, change its tag to `1.2.0` first. Also run `git pull` to get the latest
Compose configuration. For a source build or a non-Docker installation, follow **Updating** in
`README.md`.
