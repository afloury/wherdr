## New

Choose one task type when creating a task: work, research or conversation. You can also request a plan before work starts and choose whether you or the reviewer approves it, or keep the inherited setting.

## Improved

Agent cards preload the end of their conversations on hover or intent to open, making the latest messages available sooner when you open a conversation.

## Fixed

Text dictated with Spokely is captured synchronously when pasted into the message field, preventing lost text. The HTML paste fallback preserves paragraph and line boundaries.

For troubleshooting, enable the optional Paste journal in Settings › Advanced. It records diagnostic events without recording text content, stays in memory until reload and clears when disabled.

## Update

This release adds features to 2.1.0 and therefore uses version 2.2.0 rather than 2.1.1. No migration is required from 2.1.0; existing tasks and settings are kept. Node.js 22 or newer and Herdr 0.9.1 or newer are still required. Users upgrading from 1.x should follow the [2.0 migration guide](https://github.com/afloury/wherdr/blob/v2.2.0/docs/herdr-projects-1x.md).
